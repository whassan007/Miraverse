# G7 Task Notes

## Overview
Implemented deterministic texture generator `tools/textures/gen.mjs` using `pngjs` for MiraVerse Minecraft Resource Pack.

## Features
- Generates 16x16 deterministic RGBA PNG textures for items with bordered pixel-art motifs.
- Includes 5-country canonical default item list (`lb_*`, `eg_*`, `iq_*`, `kr_*`, `fr_*`) and reads all `packages/content/packs/*.json` when present.
- Writes both prefixed `<cc_lower>_<item.id>.png` and bare `<item.id>.png` (plus normalized variants) to `apps/minecraft/rp/textures/items/`.
- Generates 16x16 blue/gold `apps/minecraft/rp/textures/items/passport.png`.
- Generates 64x64 valid Minecraft humanoid skin textures for mentors `apps/minecraft/rp/textures/entity/mentor_<cc_lower>.png` (`lb`, `eg`, `iq`, `kr`, `fr`) in authentic country color palettes and attire.
