# X3 integration

Implemented responsive Phaser Play mounting, DOM country selector and completion controls, ordered chapter progress, duplicate completion guards, local souvenir persistence, and game teardown. Globe exports the pure `projectWGS84` helper and renders verified WGS84 pins with pack colors.

Scene modules are resolved from canonical capitalized filenames (Cook.ts, Build.ts, Gather.ts, Trade.ts, Word.ts), accepting default or matching named class exports. Each selected scene receives `{ pack, challenge, lang }`. Completion is accepted from game or scene events as `challenge:done` with `{ challengeId }`. Globe emits `country:select` with `{ country }`. Shared types and projection are exported from `game/shared/index.ts`.

Verification: `npm -w apps/web run build` passed. Vite reports its bundle-size warning for the Phaser-containing bundle. No frozen contracts were changed.
