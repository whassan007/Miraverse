# X1 integration notes

- `App` owns `I18nProvider`, `HashRouter`, persistent navigation, and the main content landmark. Page routes remain `/`, `/story/:lang`, `/play/:country`, `/passport`, and `/about`.
- `useI18n()` retains `{ lang, dir, setLang, t }`. Translation lookup tries the selected locale, English, the caller fallback, then the key. Unsupported language values normalize to English. UI language starts in English each session.
- `PACKS` remains an array; `STORIES` and `VOCAB` are partial language-keyed records. Stories use their declared `lang`; vocabulary objects use `lang`, and bare vocabulary arrays use their filename. Eager JSON globs support empty directories.
- Font declarations in `public/fonts/local.css` resolve device-local Arial faces, with system sans-serif fallbacks for other scripts. There are no remote font requests or bundled font binaries.
- Verification: `npm -w apps/web run build` passed (TypeScript and Vite production bundle).
- Page source and generated content were not inspected, per the task read allowlist. Browser interaction and visual checks were not performed.
