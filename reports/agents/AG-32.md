## 2. Concrete Implementation-Ready Specification for Scope (Mentor & NPC Interactions)

### 2.1 Interaction Architecture & Flow
```
[ProximityPrompt / ClickDetector on Mentor/NPC BasePart]
                             │
                             ▼
              [Client: NPCInteractionController]
                             │
            Can player interact? (Distance & Safety check)
                             │
                             ▼
         [ReplicatedStorage.MiraVerseRemotes.TalkToNpc:InvokeServer(npcId)]
                             │
              [Server: NPCServerManager]
       - Validates player distance to NPC position (anti-exploit, <= 20 studs)
       - Checks current session state (country, active challenge)
       - Retrieves localized greeting, dialogue node, and choices
                             │
                             ▼
          Returns DialoguePayload { speaker, textNative, textEn, choices }
                             │
                             ▼
               [Client: DialogueGui (ScreenGui)]
       - Displays speaker name, role badge, dual-script text (RTL supported)
       - Displays COPPA-safe canned response buttons (no free-text input)
       - Optional callback action (e.g. "Start Challenge", "Next Objective")
```

### 2.2 Client-Server Contract Specifications
#### RemoteFunction: `ReplicatedStorage.MiraVerseRemotes.TalkToNpc`
* **Invocation**: `(npcId: string) -> DialogueResponse`
* **Server Verification Rules**:
  1. `typeof(npcId) == "string"` matching an existing NPC in current player country.
  2. Player Character exists and `(character.PrimaryPart.Position - npcPart.Position).Magnitude <= 20` studs.
  3. Cooldown rate limit (minimum 0.3s between dialogue calls per player).
* **Payload Structure (`DialogueResponse`)**:
  ```luau
  export type DialogueChoice = {
      choiceId: string,
      labelEn: string,
      labelNative: string?,
      action: "start_challenge" | "next_dialogue" | "close",
  }

  export type DialogueResponse = {
      ok: boolean,
      npcId: string,
      speakerName: string,
      role: "mentor" | "artisan" | "vendor" | "cousin",
      greetingEn: string,
      greetingNative: string,
      activeGoalEn: string?,
      choices: { DialogueChoice },
  }
  ```

#### RemoteEvent: `ReplicatedStorage.MiraVerseRemotes.DialogueAction`
* **Invocation**: `(npcId: string, choiceId: string)`
* **Effect**: Server advances player quest or triggers challenge runner seamlessly via `Challenges.run(player, challenge, pack)`.

### 2.3 Visual & Spatial NPC Presentation in Roblox
* **Model Geometry**: Original procedural R15 / block rigs using native Roblox primitive parts (Head, Torso, Limbs) or CC0 procedural geometry generated in repository (`tools/assets/build-glb.ts`), dressed with country-specific primary/secondary colors defined in content packs. Zero external third-party assets.
* **Overhead Billboard**:
  * Speaker Name + Cultural Role title.
  * Distance limit: 50 studs; fade out smoothly.
* **Camera Focus (Client-side)**:
  * On interaction, smoothly tween camera `CFrame` to frame NPC shoulder-to-shoulder with the player avatar (subtle FOV shift from 70 to 65), restoring default camera on close.

### 2.4 Child Safety & Privacy Compliance
* **Zero Free-Text Input**: Consistent with repository guidelines and `Main.client.luau`, `TextChatService` remains disabled. NPC interactions accept strictly discrete predefined choices (`DialogueChoice`).
* **Session Persistence Only**: Interactions modify in-memory `SessionManager` table state; no external network requests or tracking telemetry.

## 5. Open Gaps Requiring Human Cultural Review & Runtime Proof

### 5.1 Cultural & Dialect Review Gaps (Status: `AI_REVIEWED_PENDING_HUMAN`)
* **Arabic Dialect Integrity (`ar-LB`, `ar-EG`, `ar-IQ`)**:
  * Greetings in `lb.json`, `eg.json`, and `iq.json` reflect authentic phrasing (*أهلا وسهلا يا تيتا*, *نوّرت مصر*, *هلا بيكم يا عيوني*).
  * **Gap**: Secondary NPC dialogue choices (for artisans, vendors, and cousins) have not yet been human-reviewed by native heritage educators to verify appropriate register for children aged 5–12.
* **Korean Honorifics (`ko`)**:
  * Mentor Halmeoni's speech uses grandparent-to-grandchild informal affectionate speech (*해라체* / *반말* with loving endings like *빚자꾸나*).
  * **Gap**: Child player canned dialogue choices addressing Halmeoni must strictly observe polite honorifics (*존댓말* / *해요체*); pending native speaker review.
* **Distinction of Real Geography vs. Legend**:
  * Byblos Harbor, Vieux Lyon, Cairo Khan al-Khalili, Baghdad Tigris, and Jeonju Hanok Village are verified historical locations.
  * Any NPC dialogue referencing folktales or traditions must carry the epistemic classification tag (`LIVING_TRADITION` vs. `ESTABLISHED_HISTORY` per `packages/contracts/v13/index.ts`) and must not conflate legends with archaeological facts.
