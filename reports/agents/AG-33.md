## 1. Findings & Architectural Audit

Based strictly on an inspection of repository files, the travel, spawn, and teleportation systems cross three architectural layers:

### A. Roblox Physical Architecture (`apps/roblox/src/server/MapBuilder.luau`)
1. **Lobby & Spawn Anchor**:
   - The central lobby platform is created at coordinate `Vector3.new(0, 10, 0)` with a top platform surface at $Y = 10.0$ (`apps/roblox/src/server/MapBuilder.luau#L200-L208`).
   - A `SpawnLocation` named `SpawnLocation` is positioned at `Vector3.new(0, 10.5, 0)` (`apps/roblox/src/server/MapBuilder.luau#L224-L236`).
   - Radial portals to each canonical country are arrayed at radius $R = 24$ around $(0, 10, 0)$ at $Y = 14.5$ (`apps/roblox/src/server/MapBuilder.luau#L238-L247`).
2. **Country Plaza Coordinates & Spacing**:
   - Each country's plaza center is placed along the X-axis: `Vector3.new(index * 160, 10, 0)` where $i \in \{1, 2, 3, 4, 5\}$ corresponding to `COUNTRIES` order `{"LB", "EG", "IQ", "KR", "FR"}` (`apps/roblox/src/server/MapBuilder.luau#L18`, `apps/roblox/src/server/MapBuilder.luau#L291`).
     - **LB (Lebanon)**: $X = 160, Y = 10, Z = 0$
     - **EG (Egypt)**: $X = 320, Y = 10, Z = 0$
     - **IQ (Iraq)**: $X = 480, Y = 10, Z = 0$
     - **KR (South Korea)**: $X = 640, Y = 10, Z = 0$
     - **FR (France)**: $X = 800, Y = 10, Z = 0$
   - Each country plaza includes:
     - `PlazaFloor_<CC>`: Size $(96, 2, 96)$, centered at $(X, 9, 0)$.
     - `Spawn_<CC>`: Size $(8, 1, 8)$, positioned at $(X, 10.5, 28)$ (`apps/roblox/src/server/MapBuilder.luau#L324-L335`).
     - `ReturnLobby_<CC>`: Size $(5, 8, 1.5)$, positioned at $(X, 14, 42)$ with a `ProximityPrompt` (`apps/roblox/src/server/MapBuilder.luau#L375-L394`).
     - `Mentor_<CC>`: Size $(4, 6, 4)$, positioned at $(X - 18, 13, -12)$ (`apps/roblox/src/server/MapBuilder.luau#L337-L350`).
     - `BuildOrigin_<CC>`: Size $(4, 1, 4)$, positioned at $(X + 12, 10.5, -12)$ (`apps/roblox/src/server/MapBuilder.luau#L362-L373`).

### B. Teleport Execution Paths
1. **Physical Proximity Prompt (Direct Lobby -> Country)**:
   - File: `apps/roblox/src/server/MapBuilder.luau#L278-L284`
   - Trigger: `TravelPrompt.Triggered` executes `character:PivotTo(targetSpawn.CFrame + Vector3.new(0, 3.5, 0))`.
   - Resulting landing coordinate: $(X_{\text{plaza}}, 14.0, 28.0)$.
2. **Physical Return Prompt (Direct Country -> Lobby)**:
   - File: `apps/roblox/src/server/MapBuilder.luau#L395-L400`
   - Trigger: `ReturnPrompt.Triggered` executes `character:PivotTo(CFrame.new(0, 14, 0))`.
   - Resulting landing coordinate: $(0, 14, 0)$ (directly above the Lobby SpawnLocation).
3. **Remote-Invoked Country Selection (UI Picker -> Country)**:
   - File: `apps/roblox/src/server/Core/SessionManager.luau#L99-L116`
   - Trigger: `selectCountry.OnServerInvoke` validates country, resets session state, queries `Workspace:FindFirstChild("Spawn_" .. cc, true)`, and executes `char:PivotTo(spawn.CFrame + Vector3.new(0, 4, 0))`.
   - Landing coordinate: $(X_{\text{plaza}}, 14.5, 28.0)$.
4. **Hub Contract Discrepancy (Cross-Platform Alignment)**:
   - In `packages/contracts/index.ts#L38-L112`, portal positions are declared relative to a central hub:
     - `FR`: `[0, 0, 14]`
     - `LB`: `[-13, 0, 5]`
     - `EG`: `[-8, 0, -12]`
     - `IQ`: `[8, 0, -12]`
     - `KR`: `[13, 0, 5]`
   - In `apps/roblox/src/server/MapBuilder.luau#L244-L246`, portals are mathematically computed on a circle of radius 24:
     - `angle = ((i - 1) / #COUNTRIES) * math.pi * 2 - (math.pi / 2)`
     - This creates a geometric discrepancy between Roblox procedural layout and `packages/contracts/index.ts`.

### B. Travel State Synchronization Specification
1. **Single Source of Truth**:
   - Teleportation events must update `Session.country` in `SessionManager` (`apps/roblox/src/server/Core/SessionManager.luau#L106-L108`).
   - When a player travels through a physical portal (`TravelPrompt.Triggered`), `SessionManager` must be notified via a server-side module hook or method (e.g., `SessionManager.setCountry(player, cc)`) to prevent desynchronization between player physical location and session quest state.
   - When returning to the Lobby via `ReturnPrompt.Triggered`, `Session.country` must be set to `nil` (or `"HUB"` as defined in `packages/contracts/index.ts#L47-L59`).
2. **Anti-Exploit & Streaming Safety**:
   - `Workspace.StreamingEnabled` is set to `true` in `apps/roblox/default.project.json#L29`.
   - Players must never be teleported to parts before target streaming cells are loaded. The teleportation implementation must call `player:RequestStreamAroundAsync(targetPosition)` prior to calling `character:PivotTo(...)` to avoid players falling through unstreamed terrain or parts.
