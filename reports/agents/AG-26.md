### 1.3 Roblox Implementation State ([apps/roblox/](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/roblox))
- **Handler Implementation**:
  - `apps/roblox/src/shared/Challenges/Cook.luau` manages the sequential step validation:
    - Deduplicates inputs into distinct ingredient stations.
    - Spawns interactive parts in 3D space with ClickDetectors in front of the player (`ctx.origin() * CFrame.new(off, 1.5, -10)`).
    - Color-codes parts using hex colors from `pack.items` via `ctx.itemColor(id)`.
    - Handles strict order enforcement: correct next ingredient increments `self.step`, broadcasts progress, and on completion calls `ctx.grant(self.output, 1)`, notifies success, and fires `ctx.finish(true)`.

    - Automatically builds an isolated Workspace container `Challenge_<challengeId>_<userId>`.
    - Cleans up ClickDetector connections and destroys folder instances on completion or player disconnect (`Players.PlayerRemoving`).

## 2. Concrete, Implementation-Ready Specification

### 2.1 Roblox Runtime Architecture for Cook Challenges
1. **Interactive Station Placement**:
   - For any active cook challenge, `Cook.start(ctx)` computes layout relative to `ctx.origin()` (player HumanoidRootPart planar orientation):
     $$x_{\text{offset}} = \left(i - \frac{N_{\text{distinct}} + 1}{2}\right) \times 5.0$$
   - Each ingredient station is represented by an anchored, smooth plastic part ($3 \times 3 \times 3$ studs) with color mapped from `pack.items[item].color` and a `BillboardGui` floating at $+2.5$ studs Y-offset displaying `ctx.itemName(id)`.
2. **Sequential Step Progression & Reset State Machine**:
   - `step`: Integer in range $[0, |\text{inputs}|]$.
   - Let $I = \text{recipe.inputs}$.
   - Upon input $id$:
     - If $id = I[\text{step} + 1]$:
       - $\text{step} \leftarrow \text{step} + 1$
       - Fire `ctx.notify("Added " .. ctx.itemName(id), "ok")`
       - Fire `ctx.progress({ step = step, total = |I| })`
       - If $\text{step} == |I|$:
         - Call `ctx.grant(recipe.output, 1)`
         - Call `ctx.notify("Made " .. ctx.itemName(recipe.output) .. "!", "ok")`
         - Call `ctx.finish(true)`
     - Else:
       - $\text{step} \leftarrow 0$
       - Fire `ctx.notify("Wrong order! Start again from the first step.", "error")`
       - Fire `ctx.progress({ step = 0, total = |I| })`
3. **Dual Interaction Model**:
   - **In-World Click**: Physical `ClickDetector` on station parts (max activation distance: 40 studs). Validates `who == player` server-side before calling `:add(id)`.
   - **Remote Action**: RemoteEvent `ChallengeRemotes.Action` payload `{ kind = "add", item = "<item_id>" }` handled server-side by `Cook:onAction(action)`.
4. **Economy / Cross-Challenge Flow**:
   - Completing `Cook` grants 1 unit of `recipe.output` into the player's in-memory session ledger (`ctx.grant`).
   - In all 5 packs, the subsequent `trade` challenge requires exactly this output item:
     - `LB-1-trade` needs `manoushe: 1`
     - `EG-1-trade` needs `koshari: 1`
     - `IQ-1-trade` needs `kleicha: 1`
     - `KR-1-trade` needs `songpyeon: 1`
     - `FR-1-trade` needs `galette_des_rois: 1`

### 5.2 Cultural & Historical Items Requiring Native Human Review (`AI_REVIEWED_PENDING_HUMAN`)
The following cultural representations and recipe sequences require native heritage educator and elder review:
1. **Lebanon (`LB-1-cook`)**:
   - Verification of the traditional saj manoushe preparation sequence: dough base (`flour`), brushed olive oil (`olive_oil`), and wild za'atar mix (`zaatar`).
   - Nomenclature: `manoushe` vs. plural/dialect variants (`man'ousheh`, `manaqish`).
2. **Egypt (`EG-1-cook`)**:
   - Verification of the 4-layer Koshari order (`rice` $\rightarrow$ `lentils` $\rightarrow$ `tomato_sauce` $\rightarrow$ `crispy_onions`) against authentic Cairene household traditions (some traditions layer macaroni/pasta, which is omitted here to preserve a 4-ingredient introductory format).
3. **Iraq (`IQ-1-cook`)**:
   - Mentor name divergence: `packages/content/packs/iq.json` names the elder **Bibi Amal**, whereas fallback map metadata in `apps/roblox/src/server/MapBuilder.luau` references **Bibi Nadia**. Reconciliation needed before release.
   - Verification of Eid Kleicha dough-to-filling assembly (`wheat_dough` $\rightarrow$ `date_paste` $\rightarrow$ `cardamom`).
4. **South Korea (`KR-1-cook`)**:
   - Chuseok Songpyeon sequence: kneading `rice_flour`, filling with `sesame_honey`, and steaming over fresh `pine_needles` (sol-ip) to impart aroma and prevent sticking. Confirm whether pine needles should be placed in the steamer prior to or alongside the dumplings in child-facing visual instructions.
5. **France (`FR-1-cook`)**:
   - Mentor name divergence: `packages/content/packs/fr.json` names the mentor **Mamie Claire**, whereas `apps/roblox/src/server/MapBuilder.luau` references **Mamie Colette**. Reconciliation needed.
   - Epiphany Galette des Rois sequence: puff pastry base (`puff_pastry`), frangipane / almond filling (`almond_cream`), inserting the ceramic trinket (`porcelain_feve`).
   - Safety note: Human review must verify that the inclusion of the `porcelain_feve` is clearly contextualized as a cultural tradition to prevent choking hazard misunderstandings for younger age brackets (8–12 age guidelines apply).
