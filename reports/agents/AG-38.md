## 2. Concrete Implementation-Ready Specification for AG-38

### 2.1 Multi-Tier Locale Fallback Strategy
Roblox player locales arrive via `LocalizationService.RobloxLocaleId` (e.g. `ar-eg`, `fr-fr`, `ko-kr`, `es-es`).
A multi-tier fallback cascade must be implemented:
1. **Direct Match**: Exact locale tag match (e.g., `ar-EG` -> `ar-EG`).
2. **Language/Dialect Family Match**:
   * For Arabic variants not explicitly localized (e.g., `ar-SA`, `ar-AE`, `ar-MA`), fallback to standard Arabic / default regional matrix (`ar-EG` or central Modern Standard Arabic translation).
   * For French variants (e.g., `fr-CA`, `fr-BE`), fallback to `fr`.
   * For Korean variants, fallback to `ko`.
3. **Global Base Fallback**: Any unsupported language (e.g., `es`, `de`, `ja`) falls back to canonical English (`en`).
4. **Key-Level Fallback**: If an item key in `ar-EG` is missing or empty, resolve to `en` rather than failing or showing raw lookup tokens.

export type AvatarCatalogItem = {

### 2.3 Roblox Client Catalog Localizer Module
A new shared module (`apps/roblox/src/shared/Catalog/CatalogI18n.luau`) resolving catalog strings:
* Input: `item: AvatarCatalogItem`, `localeId: string`
* Fallback resolution sequence:
  1. Exact match in `item.displayName[localeId]`
  2. Language prefix match (e.g. `string.sub(localeId, 1, 2)`)
  3. `item.displayName["en"]`
  4. Non-empty string or placeholder `item.itemId`
* RTL detection: returns `{ text: string, isRtl: boolean, dir: "rtl" | "ltr" }` so UI elements adjust `TextXAlignment` and layout flow accordingly.
