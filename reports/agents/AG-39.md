### Identified Architectural Gaps
1. **Streaming Desync Risk**: With `StreamingEnabled = true`, distant plazas (up to 800 studs away) are not guaranteed to be resident on mobile clients. Teleporting without verifying streaming residency can cause characters to fall through unstreamed geometry.
2. **Missing Touch & Device Inset Handling**: [`apps/roblox/src/client/UI.luau`](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/roblox/src/client/UI.luau) lacks `ScreenInsets` configuration (`Enum.ScreenInsets.DeviceSafeInsets`), resulting in UI clipping behind camera cutouts/notches on mobile devices. Touch button targets on the phrase bar measure under 48x48 dp on compact screens.
3. **Accessibility Feature Absence**: Text scaling, reduced motion toggles, and color contrast modes defined in portable contracts ([`packages/game-domain/index.ts`](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/packages/game-domain/index.ts#L80-L87) and [`packages/contracts/index.ts`](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/packages/contracts/index.ts#L303-L306)) are not implemented or surfaced in the Roblox client.

## 2. Concrete Implementation Specification

### A. Roblox Streaming Configuration (`StreamingEnabled`)
- **Model Hierarchy & Streaming Modes**:
  - In `apps/roblox/src/server/MapBuilder.luau`, encapsulate `TravelLobby` and each `Plaza_<CC>` as individual `Model` instances rather than loose `Folder` objects.
  - Set `TravelLobby.ModelStreamingMode = Enum.ModelStreamingMode.Persistent` to ensure the central hub and return portals never unstream.
  - Set `Plaza_<CC>.ModelStreamingMode = Enum.ModelStreamingMode.Atomic` so that all geometry, spawn points, and NPC interactables stream in as an indivisible unit.
- **Client Stream Pre-fetch & Teleportation Handshake**:
  - In `apps/roblox/src/server/Core/SessionManager.luau`, prior to calling `char:PivotTo()`, call `player:RequestStreamAroundAsync(spawn.Position, 5)` on the server to ensure surrounding chunks are preloaded.
  - On the client in `apps/roblox/src/client/`, listen to `player.CharacterAppearanceLoaded` and display a gentle non-blocking loading fade if `Workspace:WaitForChild("Plaza_" .. cc, 4)` is still resolving.

### B. Mobile Touch Controls & Responsive UI
- **Device Safe Insets**:
  - Set `ScreenGui.ScreenInsets = Enum.ScreenInsets.DeviceSafeInsets` and `ScreenGui.SafeAreaCompatibility = Enum.SafeAreaCompatibility.None` on `MiraVerseUI`.
- **Minimum Touch Targets**:
  - Wrap all interactive buttons (`UI.button`) in a `UISizeConstraint` enforcing `MinSize = Vector2.new(48, 48)`.
  - Refactor the phrase bar in `apps/roblox/src/client/Main.client.luau` to use a `UIListLayout` with `FillDirection = Enum.FillDirection.Horizontal` and dynamic scrolling (`ScrollingFrame` with `CanvasSize` adapted to orientation).
- **Mobile Click / Tap Integration**:
  - Replace raw `ClickDetector` in [`apps/roblox/src/shared/Challenges/init.luau`](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/roblox/src/shared/Challenges/init.luau#L207) with `ProximityPrompt` (`RequiresLineOfSight = false`, `MaxActivationDistance = 15`, `Exclusivity = OneGlobally`), providing native on-screen mobile action buttons and gamepad button prompts.

### C. Accessibility Engine (WCAG 2.1 AA & Neurodivergent Children)
- **High-Contrast Styling**:
  - Normal text contrast >= 4.5:1, large headings >= 3:1.
  - Add a high-contrast theme: dark panels at `#0F172A` with pure white `#FFFFFF` text and a 2px `#000000` text stroke (`UIStroke`).
- **Dynamic Text Scaling**:
  - In `UI.label`, support user-configured multipliers (`1.0x`, `1.25x`, `1.5x`) applied against base offset fonts. Ensure container frames adapt via `AutomaticSize = Enum.AutomaticSize.XY`.
- **Reduced Motion Support**:
  - Check `game:GetService("GuiService").ReducedMotionEnabled`.
  - When enabled, bypass tween animations on billboard popups and screen transitions, immediately presenting static states.

### D. Performance & Memory Budget
- **Memory Cap**: Total client memory < 450 MB on mobile devices (measured via `Stats:GetTotalMemoryUsageMb()`).
- **Target Frame Rate**: Stable 30 FPS on entry-tier mobile devices (iPhone 8 / SE2, Snapdragon 660) and 60 FPS on mid-to-high tier hardware.
- **Draw Call Optimization**: Parts spawned dynamically during challenges (e.g. `Collect_<item>` in [`Gather.luau`](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/roblox/src/shared/Challenges/Gather.luau#L26) and blueprint ghost blocks in [`Build.luau`](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/roblox/src/shared/Challenges/Build.luau#L30)) must be destroyed cleanly upon session completion via `Folder:Destroy()`, already established in `Challenges.init.luau` cleanup.
