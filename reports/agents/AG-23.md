### C. Souvenir Stamp Specification & Golden Vector (`UA`)

Adhering to [`packages/shared/stamp.md`](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/packages/shared/stamp.md):
- **Code Format:** `MV-UA1-<NNNN>-<CCCC>`
- **Alphabet:** `23456789ABCDEFGHJKMNPQRSTVWXYZ` (30 chars)
- **Salt:** `"miraverse-v0"`
- **Algorithm:** 32-bit unsigned FNV-1a hash over `miraverse-v0` + `UA1` + `nonce`.
- **Golden Test Vector Calculation:**
  - Let test `nonce` = `3456`
  - Payload string: `"miraverse-v0UA13456"`
  - FNV-1a Hash (`0x811c9dc5` init, `0x01000193` prime, mod $2^{32}$):
    - Payload ASCII bytes: `[109, 105, 114, 97, 118, 101, 114, 115, 101, 45, 118, 48, 85, 65, 49, 51, 52, 53, 54]`
    - Computed Unsigned 32-bit Value: `3650047391` (`0xD98F5D9F`)
    - Base-30 Encoding:
      - $3650047391 \pmod{30} = 11 \rightarrow$ `ALPHABET[12]` = `'E'`
      - $\lfloor 3650047391 / 30 \rfloor = 121668246$
      - $121668246 \pmod{30} = 6 \rightarrow$ `ALPHABET[7]` = `'8'`
      - $\lfloor 121668246 / 30 \rfloor = 4055608$
      - $4055608 \pmod{30} = 28 \rightarrow$ `ALPHABET[29]` = `'Y'`
      - $\lfloor 4055608 / 30 \rfloor = 135186$
      - $135186 \pmod{30} = 6 \rightarrow$ `ALPHABET[7]` = `'8'`
    - Checksum: `E8Y8`
    - Full Golden Code: `MV-UA1-3456-E8Y8` *(Marked NOT TESTED in Luau runtime until test suite runs)*
