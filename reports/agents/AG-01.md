### Exact Test Procedure for Roblox Studio

1. **Place Generation:** Run `npm run build:roblox` to emit `apps/roblox/dist/miraverse.rbxlx`.
2. **Ingestion & Invariant Check:** Launch Roblox Studio $\rightarrow$ Open `miraverse.rbxlx` $\rightarrow$ Confirm `Workspace.StreamingEnabled == true`, and confirm 0 external `rbxassetid://` URIs exist.
3. **Local Server Playtest:** In Studio, select **Test $\rightarrow$ Start Local Server (1 Player)**:
   - Confirm server console logs `MapBuilder.build()` and `SessionManager.init()` without errors.
   - Confirm avatar spawns at Central Hub `Vector3.new(0, 5, 0)`.
   - Approach Byblos pavilion (`LB`), trigger mentor **Teta Salwa** `ProximityPrompt`, verify `SelectCountry("LB")` remote fires and updates player HUD.
   - Trigger a challenge (`RunChallenge(1)`) and verify completion emits `ChallengeEnded` with stamp increment.
   - Dispatch $> 4$ calls within $0.25$ seconds to `GetState` to verify server-side cooldown throttling.
