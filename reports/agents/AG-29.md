### 2.2 Roblox Mechanics & User Flow (Child-Safe, No Free-Text Input)

1. **Trigger**:
   - Player walks within proximity of the country mentor NPC (e.g. `Teta Nahla`) at `station:<COUNTRY>:word` or uses the NPC `ProximityPrompt` ("Practice Cultural Words").
2. **Client ScreenGui (`WordChallengeGui`)**:
   - Mounts a modal child-friendly card with:
     - Header: Mentor portrait/name, challenge title, step indicator (`Step 1 of 3`).
     - Prompt Card: Prominent native script (large readable font), phonetics / transliteration underneath, audio pronunciation hint icon (or placeholder).
     - Multiple Choice Buttons (3 options): Options are shuffled/rotated deterministically. Free-text keyboard entry is **strictly excluded** in compliance with COPPA/GDPR-K zero-chat guidelines.
     - "Leave / Close" safe escape button.
3. **Server-Authoritative Validation Protocol**:
   - RemoteFunction: `ReplicatedStorage.Shared.Remotes.SubmitWordAnswer`
   - Payload: `{ country = "LB", stageIndex = 1, selectedIndex = 2 }`
   - Server checks:
     - Distance to mentor NPC $\le 24$ studs.
     - Session state matches the expected step index.
     - Validates choice against compiled pack word answer key.
   - On correct choice: Server advances player session stage and fires celebration feedback.
   - On completion of stage 3: Calls `ChallengeService.validateAndComplete(playerState, country, "word", distanceStuds)`, awards 20 Mira Tokens (or Keepsake token), and updates local in-memory passport stamp data.
4. **Error & Encouragement Handling**:
   - Gentle, encouraging feedback without failure penalties (e.g., *"Not quite! Teta says: try again!"* with infinite attempts).
