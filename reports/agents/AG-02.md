## 2. Concrete, Implementation-Ready Specification

### A. Spatial Architecture: "The Celestial Atlas Courtyard"
Rather than placing portals arbitrarily around a plain circle, the global lobby should take the form of an open-air celestial navigational pavilion featuring a 3D Interactive World Map Table (Compass Rose & World Map Mosaic) at its center.

1. **Central Rotunda (`TravelLobby`):**
   - **Center Position:** `Vector3.new(0, 10, 0)`
   - **Base Diameter:** 64 studs octagonal dais paved in light limestone tones.
   - **Central Element (3D Interactive World Map):**
     - A raised circular dais at `(0, 11, 0)` with radius 12 studs representing the World Map.
     - Flat, stylized low-poly continental landmasses created with untextured procedural parts, surrounded by lapis-blue glass water.
     - 5 interactive **Beacon Beacons/Pins** positioned corresponding to their relative geographic layout using scaled coordinate projections of `COUNTRY_WGS84`:
       - Each beacon has a subtle glowing beam (`Beam` or `PointLight`), a floating country crest billboard (`BillboardGui`), and a touch/proximity trigger.
       - Stepping near or clicking a country beacon opens the travel prompt with country metadata, current quest preview, and local dialect greeting.

2. **Portal Archways (5 Canonical Pavilions):**
   - The portal pavilions are aligned strictly to the canonical radial layout specified in `packages/contracts/index.ts` `hubPortalPosition` (scaled to 24 studs radius from center):
     - **France (FR):** `Vector3.new(0, 10, 24)` — Classical stone traboule archway, cobalt & amber palette.
     - **Lebanon (LB):** `Vector3.new(-22.3, 10, 8.6)` — Phoenician-inspired limestone arch with cedar motif, cedar-green & warm terracotta palette.
     - **Egypt (EG):** `Vector3.new(-13.8, 10, -20.6)` — Sandstone lotus-column gateway, deep Nile blue & golden brass palette.
     - **Iraq (IQ):** `Vector3.new(13.8, 10, -20.6)` — Baghdad courtyard archway with geometric brickwork, Tigris turquoise & river silt terracotta palette.
     - **South Korea (KR):** `Vector3.new(22.3, 10, 8.6)` — Traditional Iljumun / Hanok timber gate post, celadon pine green & red-pepper coral palette.
   - **Portal Gate Interaction:**
     - Arch frame with a safe semi-transparent portal surface (`CanCollide = false`, `TouchEnded`/`Touched` debounce).
     - Stepping through smoothly transitions the player (via camera fade) to `Spawn_<CC>`.

3. **World Map HUD (Client-Side World Map Modal):**
   - In addition to physical portals, players can press an on-screen **"World Map"** icon (`M` hotkey or touch button).
   - Pops up a non-blocking interactive 2D orthographic map overview (styled like an antique traveler's chart) displaying:
     - 5 Country stamps/status (Completed Chapter 1 challenges, earned souvenir stamp badge).
     - "Fast Travel" button directly triggering `SelectCountry:InvokeServer(cc)`.

### B. Luau Module Specifications

#### 1. `apps/roblox/src/server/LobbyBuilder.luau` (or refactored `MapBuilder.luau`)
- **API Contract:**
  ```luau
  local LobbyBuilder = {}
  function LobbyBuilder.buildLobby(parent: Folder): Model
  function LobbyBuilder.buildWorldMapTable(center: Vector3, parent: Instance): Model
  function LobbyBuilder.getPortalCFrame(country: string): CFrame
  return LobbyBuilder
  ```
- **Procedural Generation Rules:**
  - Zero external mesh IDs (`MeshId` / `TextureId` must not use external assets).
  - Uses basic Part primitives (Block, Cylinder, Wedge) and SurfaceAppearance or SmoothPlastic/Neon materials with exact hex colors imported from `V04Bundle.luau` or `Packs.luau`.
  - Idempotent: checks for existing `Workspace.MiraVerseMap.TravelLobby` and reuses or recreates cleanly.

#### 2. `apps/roblox/src/client/WorldMapUI.luau`
- **API Contract:**
  ```luau
  local WorldMapUI = {}
  function WorldMapUI.mount(parentGui: ScreenGui, onSelectCountry: (string) -> ()): ()
  function WorldMapUI.setVisible(visible: boolean): ()
  function WorldMapUI.updateProgress(state: any): ()
  return WorldMapUI
  ```
- **Child-Safe UI Standards:**
  - Large touch targets (minimum 44x44 points for mobile/tablet Roblox players).
  - Fully localized country names and greetings.
  - No text inputs, external web links, or user-generated text fields.

## 5. Open Gaps & Human Cultural Review Items

1. **Runtime Verification Disclosure (`NOT TESTED`):**
   - **Status:** **NOT TESTED IN ROBLOX STUDIO RUNTIME**.
   - Because execution takes place in a headless environment without an active Roblox Studio runtime or rendering client, all 3D CFrame transforms, ProximityPrompt triggers, collision layers (`CanCollide`), and UI layouts have not been visually verified in-game and require manual in-Studio playtesting.

2. **Architectural & Landmark Fact Discrepancies Needing Human Sign-Off:**
   - *Discrepancy in Mentor Names:* In [apps/roblox/src/server/MapBuilder.luau](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/roblox/src/server/MapBuilder.luau#L20-L61), fallback mentors are named `Teta Salwa` (LB), `Ammo Karim` (EG), `Bibi Nadia` (IQ), `Halmeoni Sunja` (KR), `Mamie Colette` (FR). However, canonical content packs ([packages/content/packs/LB.json](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/packages/content/packs/LB.json#L24), `EG.json`, `IQ.json`, `KR.json`, `FR.json`) and `contracts/index.ts` specify `Teta Nahla` (LB), `Teta Samira` (EG), `Bibi Amal` (IQ), `Halmeoni` (KR), `Mamie Claire` (FR).
   - *Recommendation:* Remove hardcoded diverged fallbacks and bind directly to the compiler-generated `Packs.luau` / `V04Bundle.luau`.
   - *Review Gap:* Human review is required for the architectural motifs used in the portal pavilions (e.g., ensuring the distinction between historical Lebanese mountain village stonework vs. coastal Byblos harbor motifs; verifying that Baghdadi *shanasheel* fretwork styling on the IQ portal is culturally respectful and accurate).

3. **Geographic Map Projections vs. Real Places:**
   - The map pins represent real historical and cultural regions (Byblos, Cairo, Baghdad, Jeonju, Lyon). The physical world map representation is a child-friendly educational schematic, not a political map.
   - Any localized geographical labels or regional boundaries must undergo native-speaker educator verification prior to public release.
