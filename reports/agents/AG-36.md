## 2. Concrete Implementation-Ready Specification

### 2.1 Luau I18n Engine & Dictionary Architecture
A pure-Luau internationalization module located at `apps/roblox/src/shared/I18n.luau` mirroring the web client dictionary architecture ([apps/web/src/i18n/index.ts](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/web/src/i18n/index.ts)):

```lua
--!strict
export type Lang = "en" | "fr" | "ar-LB" | "ar-EG" | "ar-IQ" | "ko"
export type Direction = "ltr" | "rtl"

local RTL_LANGUAGES: { [Lang]: boolean } = {
	["ar-LB"] = true,
	["ar-EG"] = true,
	["ar-IQ"] = true,
}

local I18n = {}
local currentLang: Lang = "en"

function I18n.setLanguage(lang: Lang)
	currentLang = lang
end

function I18n.getLanguage(): Lang
	return currentLang
end

function I18n.getDirection(lang: Lang?): Direction
	local target = lang or currentLang
	return RTL_LANGUAGES[target] and "rtl" or "ltr"
end

function I18n.isRtl(lang: Lang?): boolean
	return I18n.getDirection(lang) == "rtl"
end
```

### 2.3 Roblox RTL Layout Engine (`UI.luau`)
Extend `apps/roblox/src/client/UI.luau` with bidirectional awareness:
1. **Dynamic Text Alignment**:
   * When `I18n.isRtl()` is true, standard labels set `TextXAlignment = Enum.TextXAlignment.Right` unless explicitly centered (`Center`).
2. **Horizontal Flipping Helper**:
   * For elements positioned using horizontal scale:
     ```lua
     function UI.rtlX(xScale: number, widthScale: number, isRtl: boolean): number
         if isRtl then
             return 1 - (xScale + widthScale)
         end
         return xScale
     end
     ```
3. **Horizontal Layout / Flex Flow**:
   * In container elements (like the predefined phrase bar in `Main.client.luau#L95-L101`), when `isRtl` is true, buttons populate from index $N \to 1$ or invert the horizontal step:
     `UDim2.fromScale(1.0 - (0.01 + i * 0.248), 0.12)`.
4. **BillboardGui Alignment**:
   * Over-head speech phrases rendered in [Main.client.luau#L113-L122](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/roblox/src/client/Main.client.luau#L113-L122) must center text and maintain bidirectional isolation characters (`\u{200F}` Right-to-Left Mark) if punctuation or English numbers are mixed with Arabic text.

## 4. Dependencies & Constraints
* **Roblox Child Safety Boundary**: Predefined phrases only; open text input is disabled ([Main.client.luau#L9-L16](file:///private/tmp/claude-501/-Users-wael-Code-Miraverse/aea78164-cdca-46b5-b396-2abe6e5bab73/scratchpad/snapshot/apps/roblox/src/client/Main.client.luau#L9-L16)). Any localized phrase pack must strictly maintain fixed IDs to avoid server-side chat filter violations.
* **Deterministic Luau Compiler**: Tools run locally via `tsx tools/compiler/index.ts` without external network access or CDNs.
* **Font Compatibility**: Must rely on standard Roblox engine fonts that support Arabic shaping (such as SourceSans or modern Roblox standard system typography) without third-party asset ID dependencies.
* **Roblox Text Direction**: Roblox TextLabel/TextButton rendering does not have a native `dir="rtl"` property like HTML/CSS. Text alignment (`TextXAlignment`) and positional coordinate transformations must be explicitly managed in Luau.

## 5. Open Gaps Needing Human Review

> [!WARNING]
> The following cultural, dialectal, and runtime items cannot be assumed and require verification by native speakers and platform testers:

1. **Predefined Safe Phrases Dialect Adaptation**:
   * In English, phrases are generic (`Hello!`, `Great job!`, `Follow me!`, `Thank you!`).
   * *Gap*: Should each player broadcast phrases in their selected country's dialect (`ar-LB`, `ar-EG`, `ar-IQ`), or should there be a unified Modern Standard Arabic (MSA) option for cross-regional clarity? Native educator review is required.
2. **Distinction Between Real Geography and Pedagogical Fiction**:
   * *Real Places Cited*: Byblos old port and souk (`LB`), Sayyida Zeinab and Bab Zuweila (`EG`), Karrada and Tigris bank (`IQ`).
   * *Fictional Archetypes*: The story mentor figures (Teta Nahla, Teta Samira, Bibi Amal) are pedagogical composite characters, not historical persons. This distinction must be preserved in UI educational disclosures.
3. **Bidirectional Number Formatting & Punctuation in Roblox Engine**:
   * **NOT TESTED**: How Roblox's HarfBuzz/FreeType text shaper currently handles mixed bidirectional strings (e.g. `تحدي 1 من 5` vs `1 / 5`) across mobile, tablet, and PC clients without inserting Unicode directional marks (`\u{200E}` / `\u{200F}`). Needs runtime proof in Roblox Studio.
4. **Plaza Signage & World Space SurfaceGuis**:
   * Plazas generated in `MapBuilder.luau` create 3D signs in the workspace. Whether SurfaceGui text requires inverted billboard coordinates under RTL orientation is **NOT TESTED**.
